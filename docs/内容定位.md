# 内容定位与编辑原则

给普通年轻人的 AI 入门、技能选择与行动建议。主标题为《普通人的 AI 学习指南》，副标题为“认识 AI，减少焦虑，学会判断，从小事开始行动”。

主要面向正在学习、初入职场或寻找方向的人，兼顾其他初学者。入门不要求会编程、购买昂贵工具、完成商业项目或公开作品。

## 六章主线

认识 AI → 学会配合 → 学什么与怎样学 → 找到方向并行动。工作与机会、使用边界与日常生活分别作为第 5、6 章，按需要选读。原理、练习、观点材料和研究资料集中到附录 A—D；检索轮次留在维护记录。

## 内容取舍

概念用白话解释，方法配例子、小动作和检查；投入、失败与停止条件一并说明。对谈和文章提供思考线索，研究只支持限定结论，平台索引不当成看完视频或完成复现。职业与收入承诺不能作为催促学习的理由。

可以从一个卡点开始，允许继续、调整或停止。减少信息焦虑是内容目标，不承诺消除所有焦虑或保证特定结果。学习能力要看独立解释、修改与检查，工具输出质量不能直接代替个人能力。

当前为六章、29 节及四个附录的内容初稿，方法待读者实测。旧项目实践路线仅作为历史延伸保留，不进入主阅读版；读者无需按统一产品交付路线行动。旧版对应位置见 [内容迁移表](内容迁移表.md)。
