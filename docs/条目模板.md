# 章节小节模板

正文采用 `## 章号.节号 标题`，例如 `## 2.1 选择第一个任务`，前面加显式锚点 `<a id="entry-2.1"></a>`。附录采用 `A.1` 等编号与 `a-1` 锚点。三级小标题用文字分组，不再重复数字编号。

## 正文如何写

先用一段话说明具体问题、适用条件与原因；接着给一个能理解的例子或做法。不要把全部内容拆成几十个固定字段。

**今天可做：** 一个能尝试的小动作，说明需要什么输入。

**可以怎样检查：** 可观察的通过条件，遇到未知怎么办；学习任务要区分输出完成与独立掌握。

**投入与边界：** 需要的时间、费用、维护与复核；何时调整或停止。付费场景核实交付、预算、取消和退出条件。

**依据与范围：** 研究发现、官方规定、实测记录和作者步骤分别标注，保留对象、任务、时间、地域、阅读范围与核查日期。资料编号链接到附录 C、D；没有直接证据写作者建议。新动作未实测时不要写成已验证。

标题具体清楚。没有测量不编提效比例，没有收入记录不编赚钱数字；材料与示例为虚构时明确注明，不把提示模板当成必然有效的公式。
