# 导出与阅读

唯一正文源是 `book/` 的六个 Markdown 文件；阅读附录是 `docs/附录A-进阶原理.md`、`附录B-练习与模板.md`、`附录C-文章播客与视频.md`、`附录D-研究与官方资料.md`。免责声明、简短阅读说明与版权说明分别维护。其他文档为导航或维护记录，不再次插入阅读版。

版本与日期统一维护在 `project.json`。不要直接修改生成文件，修改源文件后重新导出。

## 生成

需要 Python 3、ReportLab 与 pypdf：

```sh
python3 -m pip install -r requirements.txt
python3 tools/build_release.py
python3 tools/build_release.py --check
```

默认使用 macOS 的 STHeiti 中文字体；其他系统提供可嵌入且覆盖简体中文的 TrueType 字体路径，字体集合取第 0 个子字体：

```sh
python3 tools/build_release.py --font /path/to/regular.ttf --bold-font /path/to/bold.ttf
```

生成 `index.html`、`阅读全文.html`、`完整指南.md`、`downloads/普通人的AI学习指南.pdf` 和 `downloads/build-manifest.json`。校验清单记录源文件与四份阅读文件的摘要，可发现未重新生成或生成文件被修改的问题。

## 固定阅读顺序

封面 → 免责声明 → 总目录 → 简短阅读说明 → 第 1—6 章 → 附录 A—D → 版权说明。HTML 没有独立封面页，首页显示标题、版本与下载入口；先呈现说明和总目录，再进入六章。维护文档不进入阅读版。

正文为 1.1、1.2 等连续章内编号，共 29 节；附录为 A.1、B.1 等独立编号。小标题可用文字分组，避免重启同一套数字。新增、移动或删除章节时同步更新迁移表、目录和交叉引用，修改生成器的预期章节数量。

## 阅读与检查

HTML 内嵌样式、脚本和内容，可离线阅读，来源链接需要网络。搜索只筛选 29 节正文；连续阅读版忽略 URL 中的搜索和章节参数，始终展示全文。附录可展开后用浏览器页面查找。目录点击和来源跳转会解除筛选并展开目标，即使再次点击当前锚点也能恢复显示；打印前展开全部内容，打印后恢复原折叠状态，打印不沿用正文筛选。

PDF 首页与内文统一使用 A4 竖版，封面图片等比居中完整显示，不拉伸或裁切。PDF 嵌入中文字体，包含两级可点击目录和分层书签，保留原始来源、地区、日期与读取限制。合并 Markdown 的本地链接改为相对于仓库根目录的路径。

生成检查覆盖六章顺序、29 节编号、来源标识、Markdown 与 HTML 链接、书签目标、全书 A4 页面尺寸和文件摘要。发布前另外渲染 PDF 检查标题、表格、中文、分页和页脚。脚本检查与模拟交互不能替代真实浏览器或读者测试。

可将根目录自行部署至 GitHub Pages。仓库地址为 `https://github.com/kkk-bot/HowToLiveWithAI`，在线阅读地址为 `https://kkk-bot.github.io/HowToLiveWithAI/`；公开包不包含原始用户讲义、私密聊天、临时渲染或旧版本下载包。
