# 阅读说明：从眼前的问题开始

这份指南写给正在学习、初入职场或暂时没有方向的普通年轻人。主线是认识 AI、学会配合、选择技能、开始行动；工作机会与家庭使用按需要选读。无需完成统一项目，也没有规定每天必须追多少资讯。

| 眼前的问题 | 阅读入口 |
| --- | --- |
| 刚接触 AI，不知道哪些说法可信 | 第 1 章；再做 B.1 的一个入门练习 |
| 已经在用，但回答经常返工 | 第 2 章；办公练习见 B.2 |
| 不知道该学什么，担心只会复制答案 | 第 3 章；独立学习检查见 B.3 |
| 想开始，却一直看资讯、选不定方向 | 第 4 章；五句话记录见 B.5 |
| 想求职、改善工作或尝试机会 | 第 5 章；求职练习见 B.4 |
| 要上传资料、执行操作或和家人一起用 | 第 6 章 |

每节先说明问题和做法，再给小动作与检查方法；涉及投入和限制时一并说明。研究、官方资料和作者建议分别标注，依据只支持写明的范围。全部练习仍未完成读者实测。

可以只选一个问题尝试，留下“原来怎么想、哪里改了、现在能做什么”的记录。结果不合适，允许调整或停止。减少焦虑是内容目标，不承诺消除所有焦虑，也不以工具数量、生成篇幅或打卡天数评价一个人。

正文采用 1.1、1.2 等章内编号；附录采用 A.1、B.1 等独立编号。想进一步理解原理看附录 A，动手练习看 B，文章播客视频看 C，研究和官方资料看 D。检索轮次与编辑历史保留在 GitHub 维护文档中，不插入主线。
