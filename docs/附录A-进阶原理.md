# 附录 A · 进阶原理

按兴趣选读，不是使用 AI 的前置考试。依据来自用户讲义与公开资料，原理解释不代表某个产品的全部实现。

<a id="a-1"></a>

## A.1 token 与逐步生成

许多自回归语言模型会根据已有内容预测下一个 token，再把新 token 加入上下文，继续生成。token 是处理文字的单位，可能是一个字、一个词或词的一部分，不固定等于一个汉字或英文单词。生成时通常需要逐步往下写；训练时可以借助掩码，在一段文本的多个位置并行计算预测任务。见 [R25](附录D-研究与官方资料.md#r25)、[R27](附录D-研究与官方资料.md#r27)、[R28](附录D-研究与官方资料.md#r28)。

可以把“周末我准备去……”看成有多种后续的句子。这个例子只说明续写方式，不代表模型只会机械接词；训练可能让模型学到复杂的语言与知识模式。但回答流畅、语气肯定，都不能证明内容正确。

对你的用法：要核查的事实给出原材料；写作时先说明对象、目的和限制。不要把“它说得很像真的”当作依据。

<a id="a-2"></a>

## A.2 Transformer、注意力与常见结构

Transformer 是一种模型架构。它把文字转为数字表示，通过注意力等计算组合上下文信息。注意力可以粗略理解为“在处理当前位置时，给其他可见位置的信息不同权重”；它不是人的专注力，也不保证模型抓住了真正重要的事实。原始 Transformer 同时包含编码器与解码器。见 [R27](附录D-研究与官方资料.md#r27)。

| 常见结构 | 怎样利用文本 | 典型用途 |
| --- | --- | --- |
| 编码器模型，如 BERT | 对输入中的位置使用双向上下文，形成表示 | 配合任务模块做分类、标注、抽取等 |
| 自回归解码器模型 | 按因果掩码利用已有文本，预测后续 token | 生成回答，也能通过输出标签完成分类等任务 |

BERT 的一项预训练任务类似“遮住部分词，再利用上下文填空”；这不是所有编码器模型的统一训练方法。见 [R28](附录D-研究与官方资料.md#r28)。把前一类叫“只理解”、后一类叫“只写作”都过于简单；也不能根据聊天产品名称推断它内部全部组件的架构。

对你的用法：选工具先看任务、效果、费用与速度，不必认为参数更多或名称更新就适合自己。架构知识可以按兴趣深入，不是开始使用的门槛。

<a id="a-3"></a>

## A.3 训练、微调、上下文与记忆

训练通过数据调整模型参数；微调是在已有模型基础上进一步调整部分或全部参数。普通聊天通常用已训练好的参数处理这次输入，本次上下文里的内容会影响回答，但不能据此说模型已经重新训练。应用保存的聊天记录或记忆功能也是另一层机制。见 [R25](附录D-研究与官方资料.md#r25)、[R28](附录D-研究与官方资料.md#r28)、[R30](附录D-研究与官方资料.md#r30)。

| 你做的事 | 应怎样理解 |
| --- | --- |
| 告诉 AI“我刚开始学英语” | 这次回答获得了背景条件 |
| 上传讲义后提问 | 应用需要读取、检索或处理材料，提供给模型 |
| 应用在下次聊天保留偏好 | 可能是保存记录或记忆功能，不等于修改模型参数 |
| 用数据开展微调训练 | 调整模型参数，属于另外的训练过程 |

对你的用法：重要任务保留一份简短背景，换对话时重新提供。上传文件是否用于未来训练，要另外核查服务的数据政策；“这次没有改参数”不能推出“文件不被保存”。

<a id="a-4"></a>

## A.4 API、工具与多模型协作

API 是程序与服务交互的接口。聊天界面方便手动使用；通过 API，程序可以提交请求、接收结果并串联步骤。对话状态怎样管理因接口而异：无状态模式需要传回所需历史，有些接口能保存状态或引用先前交互。不要把“所有 API 都不会保存对话”当作通用规则。见 [R30](附录D-研究与官方资料.md#r30)。

Agent 可以结合模型、资料和工具，围绕目标执行多步任务。多个模型也可以分工起草、检查与整理，但共同错误仍可能保留下来。“另一个 AI 同意了”不能代替外部证据。基础解释见 [R25](附录D-研究与官方资料.md#r25)；多模型分工来自 [L01](附录D-研究与官方资料.md#l01) 的系统设计讨论。

对你的用法：先理解步骤，再决定是否需要自动化。开始练习时可以只生成草稿；发送、付款或修改重要文件前核对动作与结果。API 的额度、工具费用和数据政策应另外查看，不默认包含在聊天订阅里。初学者可以暂时不学调用代码。

<a id="a-5"></a>

## A.5 训练数据记忆与模型坍塌

模型参数不是一份可以逐篇查阅的文档目录，但模型仍可能记忆并输出部分训练文本。训练数据提取研究曾在 GPT-2 上恢复原文片段，因此“没有文档索引”不能推出“绝不会泄漏”。这项研究不说明你今天使用的产品有同样的发生概率。见 [R31](附录D-研究与官方资料.md#r31)。

对你的用法：分别核查“这次如何读取”“是否保存、谁能访问”“是否用于未来训练”。没有权限上传的材料，不因为模型工作原理而变得可以上传。练习先用公开、虚构或已获准的材料；需要时删去无关的个人信息。进一步见第 6.1 节。

模型坍塌研究发现，在特定的递归训练设置下，反复用前代模型生成的数据训练后代模型，可能损失原始数据中的信息，尤其是较少出现的内容。这是关于训练数据与训练过程的问题，不是“聊天聊多了，自己的 AI 就退化”。作者预印本见 [R32](附录D-研究与官方资料.md#r32)。

另一项研究在保留原始真实数据并持续累积新数据的实验中避免了坍塌，说明数据怎样选择、保留与组合很重要。不能推导出所有合成数据都有害，或所有当前产品必然变差。见 [R33](附录D-研究与官方资料.md#r33)。

对你的用法：整理资料尽量追到原始来源，区分“有人这么说”与“有证据支持”。十篇转述同一材料的文章，不等于十个独立证据。继续学习专业知识、观察真实情况，比反复让 AI 互相复述更能帮助自己判断。
